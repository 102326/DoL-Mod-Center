# 本地模组管理验证范围

## 自动化与构建

- `npm test`：存储、恢复、前置排序、安装计划及纯 mod 文件读取测试通过。
- `npm run package`：Vue/TypeScript 类型检查、生产构建、ZIP 内容与 CRC 校验通过。
- 浏览器回归覆盖本地 ZIP 导入、启停、删除、备份恢复、跨页面旧计划拒绝、待导入列表和手机/平板布局。
- 截图来自正式版构建的隔离浏览器测试，使用合成模组；不包含玩家存档。

## Android 实机（2026-09-28）

目标平板原版游戏 APK 通过系统文件选择器分别添加两个无脚本测试包。实测内容为：

1. 两次选择累积到待导入列表，原选择未被覆盖。
2. 预览将 Base 排在依赖它的 Addon 前；取消预览后包名单、启停顺序及恢复点未变化。
3. 确认后整批安装并保存恢复点，重启后两个包实际加载。
4. 撤销导入后恢复原有启用顺序，新增测试包保留且禁用。
5. 测试完成后移除测试包并再次重启，原有包名单及启停顺序还原。

本地批量导入实机验收运行版本为 2.3.0-rc.2；2.3.1 正式版另通过类型检查、构建、待导入列表与本地界面回归。未将浏览器测试等同于全部设备实测。

## 限制

- 不代表所有 Android 文件管理器、第三方文件提供程序、异常强杀/断电或任意模组组合均已验证。
- 普通 mod 必须成功加载后才能提供启动恢复，无法修复管理器自身加载失败或 WebView 早期崩溃。
- 已安装包存储在原加载器数据库；待导入列表仅在当前页面保留。模组备份不包含游戏存档。
