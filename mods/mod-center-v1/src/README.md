# 1.3.0：诊断摘要、变更记录与紧急导出

- 运行诊断新增按日志分组的错误摘要与最近变更。分类是报错现象，不把修改重叠或时间接近当成已确认根因。
- 最近变更只记录本管理器确认成功的导入/更新、删除、启停、拖拽/前置排序、完整恢复及停用全部操作。最多100条、128KiB；不记录外部修改、不保存旧包体、不是自动回滚。历史存储失败不把已成功的管理操作误报失败。
- 完整备份页新增“紧急导出可读内容”。配置异常、缺包、坏ZIP时仍尝试保留可读字节、SHA256、原生校验结果、原配置摘要和异常清单；附带当前诊断与最近变更。单次只读事务捕获包存储，最多2000包/256MiB包体，原配置文本最多保留64KiB。
- 紧急格式 DoLModCenter.emergency.v1 明确 restorable:false，完整恢复入口拒绝此格式。完整备份/恢复原有严格校验不变。缺失、不可读、超限部分不伪造内容；启动前尚未加载的预载包来源可能无法确认。
- 不包含游戏存档、游戏本体、内嵌包体、美化type配置或缓存。包内名称/版本不等于兼容认证；原生ZIP检查只解析，不执行模组代码。
- 独立ZIP在加载后提供导出；启动前直接导出入口位于 integrated-1.3.0/DoL-Integrated.html。没有重打APK，因此原APK不会仅凭安装ZIP获得启动前入口。
- 按实机反馈关闭收起侧栏里的额外入口，旧showCompact偏好也不再启用；展开菜单入口保留。圆角按钮、颜色/阴影反馈和面板淡入支持减少动态效果。

# 1.2.2：预载分类与来源识别

- 主列表展示额外模组；游戏内嵌的预载模组放入默认折叠区域。
- 只有加载器源信息明确标为 Local 的包才识别为预载，不按名称硬编码，也不把所有当前挂载包当成预载。本地安装了同名 ZIP 时仍放在额外模组列表。
- 启停名单引用了预载包、但 IndexedDB 中没有它的 ZIP 时，不再误报“配置中缺少”。真正丢失的 IndexedDB 包仍提示；来源接口不可用时不擅自认定为预载。
- 预载包只读，不参与额外包拖拽和自动排序；自动排序保留原始名单中的预载引用位置，手动拖拽调整额外模组的有效顺序。它们仍可满足包内声明的前置依赖。
- DoLNPCCompat 0.2.0 的现有依赖声明无需改动。验证使用真实 boot.json：maplebirch 5.0.4、DoLSims 0.8.1.7 排在它之前，预载 TweeReplacer 1.7.0 可作为前置，不新增原版优化依赖，不改 NPC 或存档逻辑。
- ZIP 导出、备份和恢复仍严格要求真实包体；来源识别不会伪造包体或放宽存储写入校验。完整备份仍不打包预载资源。

# 1.2.0：包资源与依赖排序

- 本地列表显示包内版本及分类；详情展示图片、Twee 文本、样式、脚本等资源声明。声明数量不代表文件存在或兼容已验证。
- 独立图片/文本包和普通模组使用同一套导入、启停、导出、删除、拖拽管理。DoLSims 的内部资源仍随所属 ZIP 管理，不拆包删除。
- “按前置排序”生成预览，再一次性保存全部已启用包的顺序。明确 dependenceInfo 优先，保守识别的纯图片/样式包默认靠后，无约束项尽量保持原顺序。只含说明文档的 additionFile 不影响分类；带游戏脚本、Twee 或未知内容的包不自动视作美化。
- 缺失、禁用前置、别名歧义、循环、明确版本不符会阻止自动应用。版本范围沿用当前加载器接口；GameVersion 不检查；内置依赖仅参考当前运行信息。未知版本检查会提示，排序不是兼容认证。
- “美化图层 · type”显示 BeautySelectorAddon 运行时注册的图层、所属模组与图片数。独立启停、拖拽松手保存、跳转所属模组详情。越靠前越优先覆盖图片，不参与模组前置排序。
- 图层配置使用原插件初始化后的键名，在一次事务中检查旧值并写入；失败不先改内存状态。仅已验证的 ModLoader 2.101.1 / BeautySelectorAddon 2.9.0 可写，其余只读。新导入包需先重启注册图层；切换后建议重启刷新已有图片。
- 不自动启用图层，不删除图层缓存，不修改包内文件。原插件会在保存名单含失效 type 时重置选择，管理器遇到这种名单停止写入并提示，需重载后核对。
- 完整备份与配置快照仍针对模组包存储，不含独立美化 type 配置及缓存。
- 包资料扫描限 256 MiB 总包体 / 2000 个包；超限仍保留基础管理及逐包详情，自动排序不可用。

独立测试与原生加载器隔离测试通过情况见 TESTING.md。尚未进行完整游戏、Android 实机验收。本轮未重打 APK。

# DoLModCenter 1.1.0

## 1.1.0 当前行为

- 排序改为松手直接保存，不再二次确认。事务失败保留旧状态，并显示错误；过滤搜索时仍禁用拖拽。
- 手机单列，平板/PC 宽屏紧凑行布局；详情页宽屏左右分栏。头部工具栏不参与内容滚动。
- 新增“完整备份”：包体、版本、SHA-256、启停和加载顺序。包含未登记包，不包含游戏本体、内嵌包或游戏存档。无效/缺失包阻止生成可恢复备份；普通单包导出仍可用于保留原始文件。
- 恢复前必须先导出当前备份并确认保存；待恢复备份逐包验证，整体替换一个事务完成。确认期间配置或包体变化则拒绝恢复；最多 2000 个包、合计 256 MiB 原始包体，备份 JSON 文件最多 360 MiB。SHA-256 检查损坏，不认证作者。
- 独立 ZIP 提供以上功能。另有内置 HTML 构建，在模组执行前提供启动/管理/救援；不属于普通 ZIP 可实现的启动前功能。

下方 1.0.x 条目保留变更来源；排序确认流程以 1.1.0 的松手直接保存为准。

原创本地模组中心：本地管理、运行诊断和配置快照。独立界面，不依赖 ModHub。在线市场不在产品规划内，也不作为后续版本目标；用户自行获取模组包后本地导入。运行时使用 JavaScript/CSS，Python 仅用于打包。

## 安装

先导出存档和重要模组包。通过现有加载器导入此 ZIP，替换旧版同名 DoLModCenter，重启游戏后从侧栏“模组中心”打开。避免同时启用 ModHub、旧版 DoLModCenter、独立 DoLWorkbench 或 DoLDiagnostics，以免重复入口/诊断或并行修改配置。

针对 DoL 0.5.11.9 整合版的 ModLoader 2.101.1 存储接口实现；只有准确匹配已验证的加载器版本和接口才允许写入，其他版本降级只读。这里的版本指 modUtils.version，不是 ModLoaderGui 版本。

1.0.2 修正侧栏入口：展开入口放在游戏侧栏的属性/设置/存档菜单区末尾，不再直接挂到 ui-bar-body。收起时在窄侧栏顶部显示“模”快捷按钮。在“本地管理 → 入口显示设置”可以关闭它；偏好仅保存当前设备，不改存档。菜单重建后自动补回入口，避免重复。尚无 DoL 侧栏时保留备用浮动入口。

## 本地管理

查看下一次加载的启用/禁用列表，导入单个 ZIP（最多 256 MiB）、启停、调整已启用列表顺序、导出、删除、查看包内元数据。更新禁用包保持禁用状态；内嵌模组只读。操作需要确认，配置更改须重启才生效，不自动保存游戏或自动重启。

1.0.3 移除上下移按钮，改为已启用卡片左侧手柄拖拽排序。支持鼠标、触控和键盘（空格开始，方向键移动，回车确认候选位置，Esc 取消）。拖动预览后再确认保存；搜索过滤期间禁止排序，请先清空搜索。只读、禁用包、当前管理器本身不提供可用排序手柄。拖拽不改变加载器的依赖解析规则，也不证明新顺序兼容。

列表和包修改在单个 IndexedDB 事务中完成。确认后再次检查列表和目标包变化；检测到其他写入则拒绝继续。发现未登记包仅提示和提供导出，不自动删除或启用。不要同时用其他管理器修改同一配置；并发检查不能约束旧管理器跨事务的行为。

## 诊断和快照

诊断聚合加载日志、页面错误和未处理异常，提供声明式补丁重叠线索。重叠不等于实际冲突，补丁成功也不等于剧情兼容。不主动读取游戏存档变量，但错误消息自身可能包含运行上下文，导出前请查看。

“配置快照”保存下次启动的启用/禁用名单和启用顺序，支持命名、比较、JSON 导入/导出、删除，最多 10 份。它不含模组 ZIP、版本锁定或存档，也不自动恢复配置；请另行保留模组包。

诊断页中的“运行快照”记录当前已加载模组版本，和下一次加载配置是两种不同记录。保留旧工作台快照键以便读取旧数据。

## 模组资料

点击模组卡片“详情”进入独立资料页，查看版本、作者（若包内声明）、依赖和 README。返回保留搜索和列表滚动位置；详情页 Esc/Android 返回先回列表。已禁用包读取本地包体，当前运行区域读取运行包，避免混淆更新前后的版本。

Markdown 文档支持标题、段落、强调、行内/围栏代码、基础列表、引用、分隔线和简单表格；原文可展开查看。复杂扩展语法不保证完整排版。HTML、脚本和 SugarCube 宏不会执行，图片用文字占位，文内链接显示名称和地址但不自动打开；下方外部资料入口仍可点击。普通 txt 保持文本展示。不新增运行时依赖库。

优先识别浅层 README.md/readme.txt，也识别 README.zh-CN.md 和“说明/说明文档/使用说明”。只显示一份 UTF-8 文档，解压后最多 256 KiB。普通 ZIP 支持 STORE/DEFLATE；ZIP64、加密/特殊包格式、其他编码或压缩格式会提示不可预览，不影响其他管理功能。当前运行包需要加载器提供可流式读取的 ZIP 条目。

外部资料包括包内可选 homepage/website/repository/wiki 字段中的 HTTP(S) 页面和 DoL 中文 Wiki 模组目录。包内字段非加载器统一标准，链接也未经联网核验；目录入口不代表存在对应模组条目。仅用户点击时打开，不抓取 Wiki 内容、不提供在线安装或更新。过滤脚本/本地文件协议、带凭据的 URL 和常见直接下载地址；外部网站的跳转及内容不受管理器控制。

浏览器使用独立标签页并隔离 opener；Android 优先调用现有 Cordova 外部浏览器接口，若不可用则保留地址供复制，避免跳转离开游戏。此功能不新增前置模组，不需要 maplebirch 或 ModHub。
