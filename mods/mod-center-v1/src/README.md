# 共享管理模块

此目录保存 DoL Mod Center 2.0 的共享模块：本地 ZIP 存储、加载器适配、诊断、配置快照、完整备份/恢复、紧急导出和 BeautySelectorAddon type 图层管理。

当前前端入口位于 `frontend/mod-center/`，通过相对路径接入这里的模块。

## 维护边界

- 只有已验证的 ModLoader 2.101.1 写入适配；其他版本应保持只读或明确提示。
- `full.v2` 包含本地存储包体、启停名单、顺序和预载名称/版本引用；预载资源不打入备份。
- 完整备份不包含游戏存档、游戏本体、内嵌包体、type 数据库或缓存。
- `emergency.v1` 的 `restorable` 为 `false`，只能用于尽量保留可读数据和诊断，不能进入完整恢复流程。
- 导入校验读取包内声明和文件信息，不执行待导入的模组代码。

修改这里的代码时，应同时检查前端调用方和 `full.v2` 的校验、事务回滚、并发变更检查及提交后回读行为。
