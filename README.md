# DoL Mod Center

[![Latest release](https://img.shields.io/github/v/release/102326/DoL-Mod-Center?label=release)](https://github.com/102326/DoL-Mod-Center/releases/latest)
[![License](https://img.shields.io/github/license/102326/DoL-Mod-Center)](https://github.com/102326/DoL-Mod-Center/blob/main/LICENSE)

面向 **Degrees of Lewdity ModLoader** 的模组管理器。在本地完成模组整理、运行诊断、配置快照，以及本地模组配置与包体的备份恢复。聚焦本地模组管理。

> **2.3.2 正式版 · 纯 mod**：无需更换 APK。新增详细错误日志，优化统一导入、安装计划与启动恢复确认。

> [!TIP]
> 第一次使用前，请先保留游戏存档和重要模组包的独立副本。先看[安装说明](#安装与依赖)和[备份边界](#备份边界)，再导入 ZIP。

## 功能

- 详细日志保留控制台警告/错误、异常堆栈、嵌套原因与行列号，可搜索、筛选并导出报告。日志仅覆盖管理器加载后的本次会话，保留最近 300 条；常见敏感字段和本地路径脱敏，超出容量会截断。

查看路径：**诊断助手 → 原始日志与运行环境 → 详细日志**。复现问题后点击“刷新检查”，再复制或导出报告；分享前请检查内容。

- 待导入列表支持反复添加 ZIP、搜索、排序和勾选；一次最多 100 包、256 MiB。未安装列表仅保留在本次页面，确认安装后沿用加载器本地存储。
- 批量导入本地 ZIP，预检前置与版本，显示同名包的新旧版本；更新保持原启停状态。
- 启用、停用、删除和导出本地 ZIP；禁用前显示受影响的已启用模组。
- 跟手拖拽调整启用顺序，卡片让位与编号实时更新，松手保存；短暂提供撤销入口，配置变化时拒绝覆盖。搜索期间暂停拖拽。
- 拖动卡片与提示采用轻量玻璃效果，遵循系统减少动态效果偏好；自动排序仍提供依赖预览。
- 查看包内版本、作者、README/Markdown、依赖和相关资料链接；引用链接与徽章按 Markdown 排版，远程图片由用户点击后加载。
- 识别加载器报告的预载模组，并对只读来源保持只读。
- 离线诊断助手：检查下次启动配置、解释常见日志，关联最近变更并展示证据，无需模型 API。
- 在本地模组中管理 BeautySelectorAddon 的 type 图层；配置快照与完整备份统一放在备份与恢复。
- 导入前自动保存启动恢复点，出错时确认撤销上次导入。
- 通过事务、并发快照检查和恢复后回读校验保护管理器数据。

## 安装与依赖

1. 从 [Latest release](https://github.com/102326/DoL-Mod-Center/releases/latest) 下载对应版本的 `DoLModCenter-*.mod.zip`。
2. 确认游戏已经安装并启用 **ModLoader**。
3. 在 ModLoader 中导入 ZIP，替换同名的 DoL Mod Center，然后重启游戏。
4. 从游戏侧栏的“模组中心”入口打开管理器。

当前已验证的写入适配为 **ModLoader 2.101.1**；其他版本可能只能查看，无法安全写入。

## 使用

在“本地模组”中导入你已经取得的 ZIP，确认后再调整启停状态或加载顺序。配置变化通常需要重启游戏才会由加载器应用。详情页只读取包内资料和加载器提供的运行信息，外部链接由你主动点击打开。

日常使用时，导入更新靠启动恢复，大改前导出完整备份，保存常用搭配用配置快照。游戏进度仍需单独导出存档。

## 启动恢复

从本管理器导入时，旧版本包体、原启停顺序与新包在同一次存储事务中保存；保存恢复点失败时，整批导入中止。一次保留一个待处理恢复点：测试正常后选择“保留当前配置”，或选择“检查并撤销上次导入”。再次导入前需处理这个恢复点。

重新加载后会提示待验证的导入。检测到错误也不会自动回退或重启；错误不一定由这次导入造成。确认恢复后，旧包和配置恢复，新包保留但停用，再手动重启游戏。导入之后若又调整了顺序、启停状态或包体，直接回退会被拒绝，以免覆盖其他修改。可以保留当前配置释放旧恢复点，再使用完整备份或手动排查。

普通 ZIP 版的提示与恢复入口必须等管理器脚本成功加载。管理器自身无法加载、早期白屏、WebView 崩溃或进程被终止时不能保证出现入口。恢复不处理存档数据，也不撤销模组已经写进存档的内容。

## 备份边界

`DoLModCenter.full.v2` 保存本地模组 ZIP、启停名单、顺序和预载名称/版本引用。预载资源本身不在备份中，恢复时必须由目标游戏提供相同版本。

启动恢复点属于本机临时记录，不随完整备份导出；恢复完整备份会清除这个记录。

完整备份**不包含**游戏存档、游戏本体、内嵌包体、美化 type 数据库或缓存。`DoLModCenter.emergency.v1` 只尽力保留可读包体、配置摘要和诊断信息，并标记为不可恢复；它不能替代完整备份。

## 验证范围

项目包含隔离浏览器和原生加载器 fixture 测试，覆盖导入、删除、启停、排序、详情、完整备份恢复和手机、平板及 PC 的五种模拟视口。2.1 另有批量导入、恢复点跨会话读取、写入失败事务回退、外部修改拒绝、诊断规则与嵌套确认测试。元数据缓存仅在包体字节一致时复用，不跳过写入前校验；尚无真机性能提升百分比结论。自动化测试使用合成数据，不读取玩家存档或真实游戏数据库。本地批量导入流程另完成目标平板原版 APK 的文件选择、分次添加、排序安装、重启与恢复实测，详见[验证记录](docs/VALIDATION.md)。

这些结果不等同于 Android 实机、物理触控、任意 DoL 版本或全部模组组合的兼容证明。
